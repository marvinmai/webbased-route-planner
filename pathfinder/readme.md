# pathfinder

Graph reading, data structures, Dijkstra and the benchmark. See the
[main README](../README.md) for the project context.

```bash
./build.sh
./benchmark.sh <graph.fmi> <queries.que> <longitude> <latitude> <source-node-id>
# e.g. ./benchmark.sh germany.fmi germany.que 9.098 48.746 638394
```
